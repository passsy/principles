# Prefer Functional-Style Transformations Over Loops

Transform collections with .map(), .where() and .fold() instead of filling an empty list in a loop, because declarative code is shorter and easier to read.

Favor functional methods like `.map()`, `.where()`, and `.fold()` over explicit loops.
This makes code more declarative, concise, and easier to read.

Prefer extensions from `package:dartx` over `package:collection`.
